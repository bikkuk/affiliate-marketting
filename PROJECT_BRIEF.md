# Project Brief: Local AI Bench Log

Handoff document for Claude Code. This is the decided scope. Do not re open decisions already made here without asking.

## What this is

A journal site that narrates real work already happening (LocalKI, ComfyUI workflows, AI workstation builds, general AI consulting) rather than a generic affiliate blog. It exists to feed leads into Klarverk and LocalKI, not as a standalone income bet.

## Niche

Tested local AI, ComfyUI workflows, and AI workstation guidance for German and European creators and small businesses. Grounded in real hardware (RTX 5070 Ti, 16GB VRAM) and real deployment work, not generic listicle content.

## Roles

Claude Code drafts everything: journal entries, newsletter issues, metadata, commits, deploys. Nipoon only reviews and approves. See WORKFLOW.md for the exact handoff mechanism.

## Stack

Static site: Astro (or similar), Markdown/MDX content, GitHub repo, Netlify hosting. Not WordPress.

Newsletter: Substack. Automation happens through Substack's Publisher API where available rather than a scraped or cookie based client. See SETUP_CHECKLIST.md for what needs a human click first.

Social posting via MCP is a later phase, not part of this build. Do not wire it in yet.

## Business model, in priority order

1. AI installation and consulting leads
2. Paid workflow and template packs
3. Software and hosting affiliate commissions
4. Hardware affiliate commissions
5. Sponsorships and display ads, later, once traffic is real

## Budget

Maximum 150 euros for initial launch. Domain plus whatever paid tier Substack or Netlify might eventually require. Everything else should stay free tier.

## Validation window

90 days. At the end, check impressions, clicks, subscribers, and service enquiries before deciding whether to keep going, change direction, or stop.

## Content rules

Every entry needs a real basis: an actual session, an actual test, an actual number. No invented benchmarks, no invented VRAM or timing figures. If a real figure isn't available yet, leave a placeholder rather than making one up.

## Phase 2, parked for now

A second instance of this same structure, same workflow, for an ADHD focused blog and possibly a matching affiliate site for that audience. Do not start building this until the local AI bench log has at least one full review and publish cycle working end to end. Same template, different content, once phase 1 is proven.
